# YOLOv8 Object Detection and Tracking

A deep learning project for object detection and multi-object tracking using YOLOv8 and ByteTrack.

## Pipeline

- Video frame extraction
- Dataset preparation and annotation
- YOLOv8 training
- Model validation
- Object detection on video
- Multi-object tracking with ByteTrack
- Result visualization

## Technologies

- Python
- Ultralytics YOLOv8
- PyTorch
- OpenCV
- Roboflow
- ByteTrack
- FFmpeg
